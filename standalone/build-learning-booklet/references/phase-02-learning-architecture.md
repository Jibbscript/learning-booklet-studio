# P2: Learning Architecture

Layer: planning

Purpose: convert the validated concept base into measurable instruction, practice, feedback, and transfer.

Consumes: charter, current research/claims, learner prerequisites, duration, desired outcomes.

Produces: `learning-architecture.json` containing terminal outcomes, supporting objectives, prerequisite model/checks/remediation, misconception inventory, concept dependency graph, difficulty progression, guided and independent practice, assessment strategy, transfer task, and objective traceability.

## Work

1. Write four to eight observable objectives using verbs such as explain, trace, predict, compare, calculate, diagnose, implement, evaluate, or justify.
2. Order prerequisites before dependent concepts and provide compact remediation for likely gaps.
3. For each misconception, record temptation, observable symptom, counterexample, correction, exposing activity, and correction check.
4. Sequence intuition → precision → mechanism → worked example → guided practice → edge cases → comparison → retrieval → synthesis → transfer.
5. Map every objective to instruction, example, learner action, assessment, corrective feedback, and verification test.
6. Keep the final task novel enough to require transfer rather than term recognition.

## Hard Gate

- Every objective is taught, practiced, assessed, and verifiable.
- Prerequisites precede dependent concepts.
- Major misconceptions receive explicit correction.
- Difficulty fits the learner and duration.
- No planned content exists without a pedagogical purpose.
- The final assessment demonstrates the intended transfer level.

Repair claim defects in P1 and learning-design defects in P2. Any material P2 change invalidates P3–P10.

Evidence: objective traceability matrix, prerequisite ordering inspection, misconception coverage, and assessment-answer review plan.
