# P3: Information Architecture

Layer: planning

Purpose: create a coherent linear learning journey that also works as a navigable reference.

Consumes: passed charter, research, learning architecture, duration, selected visual direction.

Produces: `information-architecture.json` with section outline, heading hierarchy, linear journey, nonlinear navigation map, section transitions, content-density/effort plan, glossary plan, and reference plan.

## Section Contract

For each section record ID, title, instructional purpose, objective mapping, prerequisite dependency, claims, explanation strategy, learner action, example, visual need, interaction need, assessment need, reading effort, and transition.

Use only applicable sections, but cover motivation, objectives, prerequisite checkpoint, mental model, terminology, mechanisms, worked examples, laboratory, alternatives, failure modes, evidence, misconceptions, checks, synthesis, transfer, glossary, and references when the topic requires them.

## Hard Gate

- Every central concept and objective has an instructional home.
- Heading order and transitions support a complete linear path.
- Nonlinear navigation preserves orientation and prerequisite context.
- Density and reading effort fit the learner and duration.
- Repetition and ornamental sections are removed.
- Glossary and references can be reached without disrupting the learning path.

Repair missing concepts in P1/P2. Repair organization in P3. Material changes invalidate P4–P10.

Evidence: objective/section coverage, heading inspection, effort sum, and navigation-map review.
