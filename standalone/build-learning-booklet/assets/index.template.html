02 · Mental model

Separate input, transformation, and evidence

Mechanism-level explanations become easier to test when they expose three things: the initial state, the operation that changes it, and the observable result. A diagram should preserve those causal links rather than merely decorate the page.

Model boundary: this three-part frame organizes an explanation; it does not replace topic-specific invariants, costs, failure modes, or empirical qualifications.

Worked trace

state = 2
for step in [1, 2, 3]:
    state = state + step
# observations: 3, 5, 8

The trace makes each transition inspectable. The final value is not a separate fact; it follows from applying the operation to the current state at each step.

05 · Glossary

Terms worth retrieving

State

The information that describes a system at a particular point in a process.

Invariant

A condition that remains true across the transformations covered by a mechanism.

Transfer

Applying a learned model to a meaningfully different problem rather than repeating a memorized example.
